# Interactive Wall Calendar Component

A responsive React/Next.js calendar component inspired by a physical wall calendar, featuring date range selection and an integrated notes section.

---

## 🚀 Features

* 📅 Select start and end date range
* 🎨 Wall calendar inspired UI with hero image
* 📝 Notes section for selected dates or month
* 📱 Fully responsive (mobile + desktop)
* 💾 Data persistence using localStorage

## 💡 Design Approach

## 🧠 How It Works

* Users can select a start and end date by clicking on calendar cells
* Selected range is highlighted visually
* Notes can be added and stored using localStorage
* UI updates dynamically based on user interaction
